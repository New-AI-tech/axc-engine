## ✦ The Service Engine (Core Projects)

This repository serves as the unified interface for several specialized AI-driven micro-applications:

* **Dubai Kiosk 🇦🇪** *Headless Kiosk Architecture* A multi-cloud Headless Kiosk for luxury tourism featuring real-time Voice-to-Visual sync via Vapi.ai and Socket.io.
  
* **Hospitality Concierge** *AI Voice Receptionist* Powered by ElevenLabs and WebRTC, this voice agent automates VIP guest inquiries and reservations with human-like empathy and zero latency.

* **Faryal Al Hosary ERP** *Enterprise Retail & Booking Engine* Enterprise dress reservation and availability management for luxury rental houses and ateliers. Features a PostgreSQL availability engine and Gemini AI Stylist.

* **Instagram Concierge** *(Coming Soon)* *Social Automation* Automated high-end lead capture and luxury guest engagement integrating Meta APIs and OpenAI logic.

## ✦ Getting Started

### Prerequisites
* Node.js (v18+ recommended)
* A Gemini API Key from Google AI Studio.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/New-AI-tech/axc-engine.git
   cd axc-engine
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Rename `.env.example` to `.env.local` and add your keys:
   ```env
   GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
   APP_URL="http://localhost:3000"
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```
   The application will be available at `http://localhost:3000`.
